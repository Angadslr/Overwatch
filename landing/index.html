YOUR JURISDICTION.
01 Is this watching my computer?+
No. This website runs a fictional workspace simulation in your browser. It doesn’t read your files, connect to your coding agents, or request device permissions.
02 What can I try in the demo?+
Select an agent to filter the workspace, explore the file map, and inspect a simulated file overlap under Attention. Acknowledge it, pause the activity feed, or reset the simulation to start again.
03 Can I use the real Overwatch?+
Overwatch is in development. The repository contains the local integration work and setup documentation. Follow the project on GitHub ↗ for its current status.
04 Where does the demo data go?+
Nowhere. The sample events live in this page’s memory and reset when you reload. This page has no analytics, account creation, or backend connection, and its font is hosted locally.
